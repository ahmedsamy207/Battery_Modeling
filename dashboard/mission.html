How to generate it

  1. Open MATLAB in the repository root (needs Simscape; the pack model is matlab/step4_BatteryModel.slx with results/Simscape_BatteryPackParams.mat).
  2. In matlab/Aircraft_Mission.m, set missionType = 'x57'; at the top of the file.
  3. Run Aircraft_Mission — it simulates the scripted 192S4P pack through the mission and writes results/mission_x57.csv.
  4. Reload this page (serve the repository root, e.g. python3 -m http.server 8080 --bind 0.0.0.0).

Assumptions & method

Data source — Simscape export replay

  • Every battery quantity on this page is replayed as-is from the Simscape mission exports results/mission_x57.csv / results/mission_evtol.csv, generated by matlab/Aircraft_Mission.m.
  • The script simulates the scripted 192S4P pack — step4_BatteryModel.slx with results/Simscape_BatteryPackParams.mat — using the Simscape Battery Equivalent Circuit block: dual charge/discharge 2-RC lookup tables plus one-state hysteresis, per-temperature pack capacity, variable-step daessc solver.
  • Missions run at 25 °C from 100 % initial SOC; V_pack is the true simulated terminal voltage including RC and hysteresis dynamics.
  • No battery quantity is recomputed in the browser — the CSV columns drive the plots, KPIs and telemetry directly.

Mission profiles (matlab/Aircraft_Mission.m)

  • X-57 Maxwell — phase powers [34.0, 187.8, 189.3, 156.8, 141.6, 31.4] kW with durations [300, 30, 15, 446, 417, 293] s (NASA X-57 Maxwell, Chin et al. 2020, Table 1); pack current = P × 1000 / 750 V.
  • eVTOL / UAM — pack currents [−14, −56, −280, −200, −112, −28, −14] A with durations [300, 180, 60, 180, 720, 180, 180] s; a synthetic 2C hover-takeoff stress profile (as noted in the script header).

Pack scaling (step5_BuildPackParams.m)

  • 192 cells series × 4 strings parallel → 192S4P.
  • Cell: ≈ 35 Ah, 3.65 V nominal, 2.75–4.20 V window.
  • Pack: ≈ 140 Ah, ≈ 700.8 V, ≈ 98.1 kWh.
  • Voltage ×Ns, resistance ×Ns/Np, capacity ×Np, time constants invariant.
  • 2C current limit ≈ 2 × 140 A ≈ 280 A pack (as in Aircraft_Mission.m).

Trajectory assumptions (alt / speed / range)

  • Altitude and ground speed are trajectory segment end-values (altSegEnd, vSegEnd) defined in matlab/Aircraft_Mission.m (X-57: 8,000 ft cruise at ≈ 88 m/s; eVTOL: ≈ 300 m cruise at ≈ 60 m/s).
  • Range is the time integral of that ground speed.
  • This caveat concerns the flight trajectory only — all battery quantities are the Simscape simulation results.

Playback & controls

  • requestAnimationFrame playback loop; the speed factor (1×–100×) applies to dynamic playback only.
  • Timeline slider can be dragged at any time; plots and readouts follow the selected mission time.
  • Playback stops automatically at mission end.
  • The reserve-energy KPI uses the 20 % SOC design floor from matlab/Aircraft_Mission.m.
